# 1.10.1 可选启动迁移验证

验证日期：2026-10-10。使用 1.10.0 验证中的 Folia 1.21.11 / Worlds 3.12.4 真实旧存档，另建独立测试服；目标为 Java 25、Folia 26.2-7、Worlds 4.4.1、SimpleHomeland 1.10.1、H2。

| 验证 | 结果 |
|---|---|
| 旧配置未写新选项时启动 | 首次 API 访问前 9 个目标目录均不存在；默认按需迁移保持不变 |
| 开启启动全量迁移 | default / flat / void 各自主世界、地狱、末地共 9 个维度全部转换 |
| 转换时内存驻留 | 世界事件统计加载峰值为 1；每个维度保存并卸载后再开始下一个 |
| 启动转换完成后再按 UUID 加载 | 9 个 UUID、钻石块、17 个绿宝石和命名盔甲架全部保留 |
| 转换完成后重启 | 待处理数量为 0，迁移阶段加载峰值为 0；再次加载内容验证通过 |
| 预置 pending、不完整 staging 和目标目录 | 仅重试该维度；两个不完整副本隔离到 interrupted，所有内容再次通过 |
| 已完成迁移但数据库 nether_uuid 缺失 | 仅加载、保存并卸载该维度，UUID 补回原值；其余 8 个维度未重新转换 |
| 旧目录逐文件比较 | 与停服的旧测试服 `diff -qr` 无差异，启动转换和按需转换均未改动原目录 |
| 单元测试 | 37 项通过；新增覆盖筛选解锁维度、跳过重置、串行等待、单项失败继续、取消、卸载失败停止、5,000 项队列和复制中断重试 |

启动全量转换在插件完成启用、数据库索引加载后启动，不阻塞服务器启动线程；转换期间家园传送和世界操作暂时拒绝。转换总数、逐项结果和每 10 秒进度由控制台输出。该选项默认关闭，修改后须重启；`preload-worlds` 独立，启用时在转换结束后预加载主世界。

这次追加验证覆盖 Folia + H2。Paper、完整代理跨服链路及 XConomy 已知问题的验证范围沿用 [1.10.0 验证记录](validation-1.10.0.md)。5,000 项是调度单元测试，真实存档转换数量为 9。
